# SCT_WD_1 - Responsive Landing Page

## 🏢 SkillCraft Technology | Web Development Internship | Task 1

A responsive personal portfolio landing page built as part of my Web Development Internship at SkillCraft Technology.

## ✨ Features
- Interactive navigation menu that changes color on scroll
- Smooth hover effects with animated underlines
- Fixed navbar visible across all sections
- Fully responsive (mobile, tablet, desktop)
- Smooth scroll between sections
- About, Skills, Projects and Contact sections

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)
